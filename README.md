# EntityDistance

A Minecraft Fabric mod focused on entity distance and rendering behavior.

## About

**EntityDistance** is an open-source Minecraft mod project exploring how entity distance can be used to influence rendering behavior and visibility.

The project aims to provide a foundation for experimenting with entity distance mechanics through the Fabric modding platform.

Development is ongoing, and features may change as the project evolves.

## Development

EntityDistance is built using the Fabric modding toolchain.

To get started with Fabric mod development, refer to the official documentation:

- [Fabric Documentation](https://docs.fabricmc.net/develop/getting-started/creating-a-project)

### Requirements

- Java Development Kit (JDK) compatible with the target Minecraft version
- Minecraft
- Fabric Loader
- Fabric development environment
